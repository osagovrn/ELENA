Одностраничный сайт мастера перманентного макияжа. Чистый HTML / CSS / JS.

**Домен:** `https://elenaperm.ru/` (GitHub Pages + собственный домен).

> Этот README лежит в `прочее/` — он не нужен для работы сайта и на GitHub не выкладывается. Здесь же лежит `.gitignore` (не нужен, если вы не работаете через git-консоль) и всё остальное, что касается сайта косвенно.

## Структура репозитория (что реально грузим на GitHub)

```

Всё, что в этом списке, перетаскиваете на GitHub. Папку `прочее/` — не трогаете, она остаётся только у вас на компьютере.

```

## GitHub Pages

1. Загрузите содержимое папки сайта (список выше) в корень репозитория — включая скрытые файлы `.nojekyll` и `CNAME`. При перетаскивании папки браузер обычно подхватывает скрытые файлы автоматически, но после загрузки стоит открыть репозиторий на GitHub и проверить, что `CNAME` и `.nojekyll` там видны.
2. Settings → Pages → Source → Deploy from branch → `main` / root.
3. Settings → Pages → Custom domain → впишите `elenaperm.ru` и дождитесь зелёной галочки DNS-проверки (если ещё не привязан — без этого шага все ссылки на сайте, которые жёстко указывают на `https://elenaperm.ru/`, будут вести не туда, где реально откроется сайт).
4. Включите принудительный HTTPS (галочка "Enforce HTTPS" появится после проверки домена).
5. Если домен репозитория/пользователя всё же изменится — обновите ссылки в `index.html`, `robots.txt`, `sitemap.xml`, `CNAME`.

## Языки

`js/i18n.js` (RU/EN/ZH/UZ) + `js/i18n-extra.js` (KA/OS/KY).  
Переключатель в шапке — выпадающий список. URL: `/?lang=en`.  
Все 7 языков покрывают 100% ключей (включая тексты отзывов и alt-описания фото). Если добавляете новый блок в `index.html` через `data-i18n="..."`, не забудьте прописать этот ключ во всех 7 языках, иначе на этом языке текст останется русским.

## Картинки

Каждое фото хранится в двух форматах: `.jpg` (обычный) и `.webp` (легче на ~30–40%). В `index.html` они подключены через `<picture>` — WebP отдаётся браузерам, которые его поддерживают, JPG — всем остальным. При замене/добавлении фото создавайте обе версии и подключайте так же через `<picture>`.
