# Всплывающее уведомление (баннер) — инструкция

Баннер нужен для разовых объявлений: отпуск, временная пауза в записи, акция и т.п.
Показывается один раз при первом заходе посетителя (запоминается в браузере).

## Где менять

Файл `js/script.js`, самое начало — блок `ANNOUNCEMENT_CONFIG`:

```js
const ANNOUNCEMENT_CONFIG = {
    enabled: false,    // true = показывать, false = скрыть
    title: 'Отпуск',
    text: 'До 12 сентября. Запись на новые процедуры — после возвращения.',
    icon: '🌴'
};
```

- **enabled** — `true`, чтобы включить баннер, `false` — чтобы выключить. Ничего больше удалять/трогать не нужно.
- **title** — короткий заголовок.
- **text** — текст. Можно перенести строку через `<br>`, например: `'До 12 сентября.<br>Запись — после возвращения.'`
- **icon** — любой эмодзи или пустая строка `''`, если иконка не нужна.

## Как это работает

- При первом заходе посетитель видит баннер поверх сайта.
- Как только он его закроет — баннер для него больше не появится (браузер запоминает это через `localStorage`).
- Если вы поменяете `title` или `text` — баннер снова покажется всем, даже тем, кто уже его закрывал (это специально, чтобы новое объявление увидели).
- Если просто оставить `title`/`text` прежними и переключить `enabled: false → true` позже — тем, кто уже закрывал именно этот текст, баннер повторно не покажется. Чтобы показать заново тот же текст — допишите в конце текста невидимый пробел или любой символ, это создаст «новую» версию баннера.

## Что не трогать

Саму разметку баннера в `index.html` (блок `#announcementOverlay`) и стили в `css/style.css` менять не нужно — там ничего не хранится, весь текст подставляется скриптом из `ANNOUNCEMENT_CONFIG`.
